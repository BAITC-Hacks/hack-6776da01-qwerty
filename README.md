# HackAlem AI

Локальный прототип системы автопротоколирования совещаний.

## Возможности

- принимает MP3, WAV, M4A или MP4;
- локально распознаёт речь через Faster Whisper;
- автоматически определяет язык (русский/казахский/смешанная речь);
- показывает транскрипт с временными метками;
- назначает локальные метки говорящих `SPEAKER_00`, `SPEAKER_01`;
- использует обращения по имени для подписи следующей реплики;
- выделяет потенциальные поручения, ответственных и сроки;
- формирует саммари;
- экспортирует результат в DOCX.

Аудио и текст не отправляются во внешние облачные API. При первом запуске
скачивается локальная модель распознавания в каталог `models/`.

## Запуск на Windows

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app\main.py
```

Откройте адрес из терминала, загрузите аудиозапись и нажмите «Создать протокол».

### Проверка транскрибации без интерфейса

```bat
py -c "from app.transcription import transcribe_audio, segments_to_text; print(segments_to_text(transcribe_audio('meeting.mp3', 'small')))"
```

По умолчанию включён локальный акустический fallback: голосовые признаки
сегментов кластеризуются в локальные дорожки и получают метки `SPEAKER_00/01`.
Для полноценной акустической
диаризации можно отдельно установить `pyannote.audio`, скачать checkpoint в
локальный кэш и задать `HF_TOKEN` только для доступа к checkpoint. Аудиофайл
при этом остаётся локальным; если pyannote не настроен, приложение продолжает
работать на fallback без облачных API.

## Ограничения текущего MVP

Акустический fallback является эвристикой и не распознаёт личность человека;
для длинных реплик или близких тембров возможны ошибки. Для демо с реальными разными голосами рекомендуется подключить
локальную модель pyannote; имена участников всё равно нужно сопоставить с
`SPEAKER_00`, `SPEAKER_01` вручную или через голосовые профили.

Если в реплике есть обращение вроде «Гульмира Сериковна, вам слово» или
«Нурлан Сагатович, какая ситуация?», следующая реплика получает имя из
обращения. Это текстовая подсказка, а не подтверждение личности по голосу;
при отсутствии обращения остаётся акустическая метка `SPEAKER_XX`.
