# HackAlem AI

Локальный прототип системы автопротоколирования совещаний.

## Возможности

- принимает MP3, WAV, M4A или MP4;
- локально распознаёт речь через Faster Whisper;
- показывает транскрипт с временными метками;
- выделяет потенциальные поручения, ответственных и сроки;
- формирует саммари;
- экспортирует результат в DOCX.

Аудио и текст не отправляются во внешние облачные API. При первом запуске скачивается локальная модель распознавания.

## Запуск на Windows

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app\main.py
```

Откройте адрес из терминала, загрузите аудиозапись и нажмите «Создать протокол».

## Ограничения текущего MVP

Текущая версия использует локальную транскрибацию и базовые эвристики для поручений. Полноценную диаризацию и более точное понимание поручений следует добавить перед финальной демонстрацией.
