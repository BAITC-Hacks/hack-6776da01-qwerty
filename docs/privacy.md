# Защита данных демонстрации

В проект добавлен локальный анонимизатор транскриптов. Он заменяет распространённые чувствительные данные:

- email → `[EMAIL]`;
- телефон → `[PHONE]`;
- 12-значные идентификаторы → `[IIN]`.

Пример:

```bat
py tools\anonymize_transcript.py samples\demo_transcript.txt
```

Исходный файл не изменяется: рядом создаётся файл с суффиксом `.anonymous`. Анонимизатор эвристический, поэтому перед публикацией записи результат нужно просмотреть вручную.
