# Контроль качества протокола

Модуль `app/quality/` проверяет результат обработки без отправки данных во внешние сервисы.

Проверяются:

- наличие транскрипта и саммари;
- количество речевых сегментов и говорящих;
- количество найденных поручений;
- заполненность ответственных;
- заполненность сроков;
- предупреждения о возможной проблеме диаризации;
- итоговая оценка качества от 0 до 100.

Проверка демонстрационного результата:

```bat
py tools\evaluate_demo.py samples\expected\demo_protocol.json
```

Код завершения `0` означает, что обязательных предупреждений нет. Код `1` означает, что результат требует ручной проверки.

Модуль намеренно отделён от основного Streamlit-интерфейса: его можно подключить позже без изменения существующих файлов.
